SINet-v2 / S2C (HKU-IS -> COD10K) — Table 1 "Ours" row

Run every command from the repo root: /home/ai-server/Public/lab/Diffusion_Inpaint/S2R-COD

-------------------------------------------------------------------------------
0. PRE-FLIGHT
-------------------------------------------------------------------------------
uv run python preflight.py --network SINet-v2
-------------------------------------------------------------------------------
1. TRAIN  (both CSRDA rounds + the CLS step, one command)
-------------------------------------------------------------------------------
uv run python MyTrain.py --network SINet-v2 --task S2C --gpu 0 --iteration 2 \
  --save_model ./Snapshot/SINet-v2/S2C/ \
  --target_root ./Dataset/Target/ --val_root ./Dataset/Val/CAMO/ \
  2>&1 | tee train_sinetv2_s2c.log

# Notes:
#  * --gpu is now free to be anything. Before the MyTest.py fix, training on --gpu 1
#    produced a checkpoint that MyTest.py could not load. Keeping --gpu 0 is still the
#    simplest default.
#  * NEVER run SINet and SINet-v2 at the same time: both write
#    ./Dataset/Source/HKU-IS_iteration2/ and CLS rmtree's it on entry.

------------------------------------------------------------------------------
2. ARCHIVE the CLS pseudo-label set (before training the other network)
-------------------------------------------------------------------------------
mv Dataset/Source/HKU-IS_iteration2 Dataset/Source/HKU-IS_iteration2-SINetV2

-------------------------------------------------------------------------------
3. INFERENCE on COD10K-test
-------------------------------------------------------------------------------
uv run python MyTest.py --network SINet-v2 --gpu 0 \
  --model_path ./Snapshot/SINet-v2/S2C/Tea_epoch_best.pth \
  --test_save ./Result/SINet-v2/S2C

ls Result/SINet-v2/S2C | wc -l          # must be 2026

# Notes:
#  * --gpu is NEW (added with the fix). It no longer has to match the training GPU;
#    the checkpoint is now loaded via map_location='cpu' and is device-agnostic.
#  * MyTest.py now asserts that all 880 checkpoint tensors were actually copied.
#    If the assert fires, STOP — do not evaluate the masks.
#  * MyTest.py hard-codes ./Dataset/Test/{Image,GT}/ regardless of any flag.
-------------------------------------------------------------------------------
4. EVALUATE  (must cd into Eval/)
-------------------------------------------------------------------------------
cd Eval && uv run python MyEval.py \
  --gt_root  ../Dataset/Test \
  --pred_root ../Result/SINet-v2/S2C \
  --txt_name  SINet-v2/S2C ; cd ..

cat Eval/Eval/eval_txt/SINet-v2/S2C/_eval.txt
