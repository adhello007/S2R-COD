## 1. Why this is a port-and-repair, not a fresh build

A3 was **fully run before the rebuild** and then deleted with the rest of the old package
(commit `96fe223`). The original is recoverable at
`git show 96fe223^:evidence/a3_appearance_signature.py` and already carried the whole control
battery — the JPEG floor, the true null, the cross-dataset baseline, the k-NN coverage panel — and
already demoted its own headline. `A3_SCOPING.md` establishes this and identifies four defects to
repair. The original is **read, not imported and not executed**: the rebuild permits exactly one
in-tree implementation and no resurrected side file.

| # | Defect in the original | Repair |
|---|---|---|
| **R1** | Its real-vs-real "null control" split the target set in sorted-filename order. `Dataset/Target/Image` is a **two-dataset mixture** (COD10K + CAMO, see §4), so that split separated the mixture from itself — and it was not even a clean dataset split, because COD10K filenames are ordered taxonomically, conflating dataset origin with taxonomy | The **clean COD10K-vs-CAMO probe**, which has never been computed, is reported **in the same table as the headline**. The sorted split is reproduced beside it as a *labelled control* so the original defect is visible rather than described |
| **R2** | The decision rested on AUC, which is saturated: the headline, the cross-dataset baseline and the self-separation control all crowd into the top hundredths of a scale whose ceiling is 1.0, so no margin is stateable | The decision moves to the **paired coverage delta** (`T1`, §5), a within-content intervention: identical foregrounds, identical masks, one manipulated variable, one fixed target manifold. AUC is reported as description and decides nothing |
| **R3** | Cohen's *d* was computed **in-sample** — the axis was fitted on the training half, then every row was projected onto it and the absolute value taken. C1 later *measured* that this estimator manufactures large effects from nothing | **Four** *d*'s per row: the original estimator (so the old figure is reproduced, not asserted away), the same logistic axis held out, and C1's imported mean-difference estimator in both variants. `T8` reproduces C1's demonstration inside A3's own data |
| **R4** | Every probe and coverage number came from the *local* re-generation. The **authors' pool** — the one `MyTrain.py` actually reads — was never probed (`REBUILD_PLAN.md` §5 item 5) | **Both** synthetic pools are reported, always, labelled. E0 measured them as genuinely different samples of one generator, so agreement between them is an independent replication rather than a repeat |

**Method identity for the *d* is by import, not by inspection.** The held-out estimator is the same

with it and the two cannot drift apart.

### Command run

```bash
LAKE-RED/.venv/bin/python rebuild/A3/a3_appearance_signature.py
```

`--steps` selects steps (default all six), `--tags` the embedder spaces, `--workers` the pixel-panel
pool, `--batch` the embedding batch, `--no-log` prints the block without writing it. `s1` always
runs: every other step consumes its index masks.

## 3. Steps

| Step | What it does |
|---|---|
| `s1` | **Preflight.** Every E0 cache A3 reads is loaded and checked against `e0_cache_summary.csv`; cache name lists are checked identical across embedder spaces; every input directory is re-digested against `e0_input_digests.csv`; D2's leaked names are resolved against E0's own target listing; the COD10K / CAMO / leaked index masks are built as pure name predicates; and the **index-wise alignment** of the three HKU-IS pools is asserted |
| `s2` | **Embed what E0 does not have** — NC4K, the JPEG-quality sweep, and the darkening control — into `rebuild/A3/cache/` using E0's declared pipeline and cache layout |
| `s3` | **The separability ladder.** Fourteen rows × three embedder spaces: the two headlines, the paired real baseline, the leak-sensitivity row, the COD10K-vs-CAMO self-separation control, both real-vs-real splits, the identity-preserving floors, the second null, and the cross-dataset row. Each yields held-out accuracy and AUC plus four effect sizes |
| `s4` | **Coverage — the decision.** k-NN precision/recall against the target manifold for both synthetic pools, the raw input pool, NC4K, both ceilings and the self-separation pair, swept over four values of `k`. `T1` is evaluated here |
| `s5` | **Distance and spread**, descriptive. Unbiased polynomial-kernel MMD² for every ladder row — an *unsaturated* companion to AUC — and C1's trace-covariance / log-det / effective-rank comparison |
| `s6` | **Pixel statistics**, secondary. The original's panel 1 ported over all 4447 foregrounds and all three pools: mask-restricted background luminance, per-channel shift, and the foreground→background colour correlation |

Every step's numbers go to the log block first. Nothing is a finding until the committed script
produces it.

## 5. Declared thresholds

Fixed before the run, written into the script as constants. **`T1` is the decision**; everything else
either licenses it, calibrates it, or is a sanity gate. `T6` is a *flag* — it fires when a finding
would be vacuous, so a `FAIL` there is the good outcome.

| # | Condition |
|---|---|
| **T1** | **PRIMARY.** `recall(generated) < recall(raw HKU-IS)` by at least a **15% relative** margin, in at least **2 of the 3** embedder spaces, for **both** synthetic pools |
| `T2` | `recall(generated)` is below the random-split ceiling in every cell |
| `T3` | The true null is genuine: `\|AUC − 0.5\| ≤ 0.05` in every embedder space |
| `T4` | The old sorted-split defect reproduces at `AUC > 0.75` |
| `T5` | The clean COD10K-vs-CAMO self-separation probe is computed and reported beside the headline |
| `T6` | **Vacuity flag.** Some identity-preserving control exceeds `AUC 0.90` (the trigger declared at `REBUILD_PLAN.md` §3-A3) |
| `T7` | The held-out *d* on random halves is a genuine null, `\|d\| < 0.30` |
| `T8` | The **in-sample** *d* on random halves exceeds `0.50` — reproducing C1's demonstration inside A3's own data, which is what disqualifies the original's figure |
| `T9` | The three HKU-IS pools are index-wise aligned, 4447 of 4447 |
| `T10` | The coverage-delta sign is identical in all three embedder spaces |

**The margin is relative, not absolute, and that is deliberate.** Absolute recall levels differ
between embedder spaces, so a fixed margin would confound embedder-robustness with scale.

**Both refutations are pre-committed as publishable.** If `T1` fails: *LAKE-RED does not measurably
reduce coverage of the target manifold relative to its own input pool*, and the coverage argument is
retired. If the headline held-out *d* does not exceed the COD10K-vs-CAMO control: *LAKE-RED's output
is no further from the target than two real camouflage datasets inside that target are from each
other.* Neither is a failure to report.

The old package's values are pinned as `OLD CLAIM` lines from the frozen record at
`REBUILD_PLAN.md` §4, plus the old-log values that table omits. A record for `REVISION_TABLE.md`
only — never an input, never a baseline, never a target.

## 6. Known limits, declared

- **A3 is a distributional characterization, not a training-utility bound.** A distant or
  low-coverage synthetic set can still improve a model. A3 supplies a candidate mechanism consistent
  with the absence of a resolvable gain; it does not demonstrate that no gain exists.
- **k-NN precision/recall is a manifold *estimate*.** It depends on `k`, so `k` is swept and the
  anchor is declared in advance rather than chosen after the fact. It also depends on L2
  normalisation, which is applied — **our stated choice**, since the original sources never said
  whether they normalised.
- **MMD is kernel-dependent** (degree-3 polynomial, the KID kernel) and carries no threshold. A
  Fréchet distance was considered and **declined**: at these sample sizes a 1024×1024 covariance
  rests on roughly four samples per dimension. The absence is a choice, not an oversight.
- **The NC4K control's cleanliness is scoped to the COD10K axis.** D2_NC4K measured NC4K against the
  COD10K-train images only; the CAMO portion of the target set was not part of that check.
- **The identity-preserving floors are a sweep over one dimension, not a full sweep.** Quality and
  darkening levels bracket the original's single settings; other corruptions are untested.
- **The headline is reported against the 4040-image mixture** because that is what the method
  adapts to. The COD10K-only and CAMO-only decompositions are reported in the same table so the
  mixture cannot inflate the finding unnoticed.
- **`dinoB/224` has no rebuild cache**, so one of the original's three *d* sub-values has no
  counterpart here and is logged `NOT-REPRODUCIBLE` rather than substituted.
