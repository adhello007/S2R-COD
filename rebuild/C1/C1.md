## 2. Phase 0 — the six gates, and what HALT means

`run_preflight()` runs all six, writes `out/c1_preflight.json` **even on failure**, and the
measurement raises `SystemExit` before loading a single array if any gate fails. **There is no
fallback, no default, and no `--force` flag anywhere in C1.**

| Gate | What it asserts |
|---|---|
| **signal** | `target_es` exists, is fully populated, sums to the right target count, and is strictly positive. Plus an **AST scan asserting C1 never references the endpoint column** anywhere in its source |
| **cluster_source** | Row counts match B1's logged `k` per embedder; assignment `k`/`seed`/`embedder` agree; centroid shapes match. Plus an **AST scan banning every clustering call and `sklearn.cluster`** — C1 consumes B1's partition and never fits one |
| **embedder** | Every space loads with the right shapes, and re-reading the first space *after* loading all of them still returns the first |
| **representation** | R2/R3/raw row alignment; then **pixel-level**: background is exactly the flat constant, object untouched, fresh re-embed matches the cache, **and a discriminative control** — the full scene and the render must both score *lower* against the cache than the cutout does |
| **leakage** | D2's measured leaked names are absent from the partition; and every endpoint × HKU-IS-pool pair in D2's matrix has zero collisions, read from the matrix rather than restated |
| **freshness** | E0's own `step_independence()` is **imported and called**, not re-implemented; plus a sampled re-hash of the primary inputs against E0's manifest |

**The gates were self-tested.** A probe file reading the endpoint column and calling `KMeans` was
injected: gate 1 caught the column read, gate 2 caught both the import and the call, and both
returned to PASS when it was removed. A gate that has never failed is not evidence.

## 3. The measurement

### Allocation
Temperature-softmax over `target_es`, with `T = alpha · sd(es)` so the temperature is **scale-free**
and comparable across embedders with different `k`. Integer budgets by **largest-remainder**, ties by
ascending cluster index, so `sum(n_c) == B` exactly and deterministically.

### Selection
Cosine of every cutout to every centroid in **R2** — the grey-128 cutout, because that is what a real
pipeline has at selection time: the foreground exists, the render does not. `argsort(kind='stable')`
makes equal cosines resolve by ascending row index.

Because the budget is a set of **distinct** images, clusters are served in an order and each takes the
next not-yet-claimed row. `n_displaced` records how often a cluster's next choice was already taken.

### Sweeps

| Axis | Grid |
|---|---|
| `B` | 250, 500, 1000, 2000, 3000, **4447** (the pool ceiling) |
| `alpha` | starts at 8 values, then **extended** until both degenerate ends are reached |
| embedder | `dinoL518` (primary), `dinoL224` (sensitivity) — **judged separately, never averaged** |
| representation | d measured in **both** R2 and R3 |

Degenerate ends are defined numerically: concentrated when `max(p) ≥ 0.95`, uniform when
`TV(p, uniform) < 0.01`, with caps at `alpha ∈ [1e-4, 1e3]`.

### Effect size
`‖Δmean‖`, then Cohen's *d* on the projection onto the difference direction. Because that direction
is fitted to the data, **the headline is `d_heldout`**: direction estimated on one half, evaluated on
the disjoint half. `d_insample` is reported beside it as the optimistic bound.

### Amendment A1 — mandatory intervals
Every cell reports `ci_draws` (over the random draws), `ci_boot` (bootstrap of the evaluation halves),
and **`ci_combined`** — their conservative union, which is the interval every judgement uses. Band
assignment uses the **interval**, not the point; `ci_straddles_band` is logged for every cell.

### Amendment A2 — mandatory order sensitivity
Every cell is selected under five serving-order families — `desc_nc` (primary), `asc_nc`, `asc_index`,
`desc_es`, and ten shuffled permutations. The spread is a **paired** comparison: every order,
including the primary, is evaluated over the *same* draws, so a difference between orders cannot be an
artefact of their having seen different random arms.

### The ceiling, and the null calibration
`d_max_possible` puts the entire budget in the single highest-ES cluster, bounding what targeting could
ever achieve at that budget. And at `B = 4447` both arms are the entire pool, so the true difference is
exactly zero — `‖Δmean‖` must vanish (asserted), which makes that point a **null calibration** of the
estimator.

## 4. Declared thresholds

Written into the script before running.

| # | Condition |
|---|---|
| 1 | All six Phase-0 gates pass before any array is loaded |
| 2 | `‖Δmean‖ = 0` at the pool ceiling |
| 3 | The peak \|d\| exceeds the magnitude of the null calibration |
| 4 | **A1**: the held-out CI at every peak cell lies entirely within one verdict band |
| 5 | **A2**: `d_order_spread < 0.05` at every peak cell |
| 6 | Both degenerate ends of the temperature sweep were reached in every space |
| 7 | The two embedder spaces agree on the verdict band |

**Verdict bands**, judged on `d_heldout` at `argmax_B` per embedder × representation, over
non-degenerate cells: `|d| < 0.2` → **CONFIRMED**; `0.2 ≤ |d| < 0.5` → **AMBIGUOUS**; `|d| ≥ 0.5` →
**REOPENS**. A straddling CI overrides the point estimate with `INCONCLUSIVE-CI-STRADDLES`.

## 5. Known limits, declared

- **Cohen's *d* is a mean-shift measure along a single direction.** Two sets can share a mean and
  differ in variance, higher moments, or coverage. A small *d* shows the arms share a **centre**, not
  that they are the same **set**. Logged regardless of outcome.
- **The direction is fitted**, which is why the headline is held-out and why the ceiling doubles as a
  null calibration.
- **The partition is weakly separated** (B1: silhouette 0.1465 / 0.1600 / 0.0568) and the allocation
  signal is only a moderate predictor of endpoint error (B1 completion II). C1 inherits both.
- **Selection is by R2 only.** Selecting by R3 needs renders before selection; out of scope, stated.
- **C2 has not been run.** Any shape comparison is against C2's *analytic* design, and `|Ds|` is
  `UNVERIFIED`.
- **Seed robustness of the ES signal is `UNVERIFIED-DEFERRED`.**
- **`clipL224` is disqualified** as a C1 space: no interior silhouette peak, `k*=5` on B1's guard.
